# 词汇故事集 · 本地精读网站

把 `词汇故事集/` 里的 30 篇四级词汇故事，做成一个能逐句对照、能查词、能造句、能自测的本地网页。

---

## 一、怎么用

### 方式 A：双击打开（最省事）

直接双击 `site/index.html`，用 Chrome / Edge 打开即可。全部资源都是本地文件，**不联网也能用**。

### 方式 B：本地服务器（推荐，可深链）

```bash
cd D:\CET4\web
node tools\serve.mjs 8848
# 然后打开 http://127.0.0.1:8848/index.html
```

好处是可以用 URL 直接跳到某一章的某个视图：

| 链接 | 打开什么 |
| --- | --- |
| `index.html#ch01/read` | 第 1 章 · 精读 |
| `index.html#ch07/vocab` | 第 7 章 · 词表 |
| `index.html#ch12/cards` | 第 12 章 · 闪卡 |

## 二、三个视图

### 1. 精读（`read`）

- **默认展开逐句对照**：左边英文原句，右边中文译文，一句一行对齐。
- **两种阅读姿势**，点段落条上的「壹 贰 叁」印章切换：
  - **连续阅读**：整段英文像一本书一样连着读，不打断；
  - **逐句对照**：展开成左右两栏。
- **句中目标词**带加粗的蓝色下划线。点一下弹出词条卡片：音标、词性、释义、**原文例句**（就是你正在读的那句）、**造句**（例句 + 中文 + 用法提示）、朗读按钮、掌握度。
- **朗读**：
  - 每句话左边序号下面有个 **♪**，点一下读这一句；
  - 段落条上的「播放本段」支持暂停、继续，并显示句子进度；音色提供词边界时也会逐词高亮；
  - 正在朗读的句子整行微微泛红，`Esc` 随时停。
- 顶部「展开全部译文 / 收起全部译文」一键切换。

### 2. 词表（`vocab`）

- 每篇约 139 个目标词，单列展示，同一个词的多个义项放在一起：
  - 音标 + 词性 + 释义
  - **原文**：这个词在正文里出现的句子 + 对应译文，「定位原句」会居中并闪亮提示，顶部「返回词表」回到原来的查询和位置。原句和造句都可独立朗读
  - **造句**：一个可迁移的例句 + 中文翻译 + 用法/搭配提示
  - **连读单词和句子**：依次朗读单词、卡片上的原句和造句，重复句子只读一次；再点可暂停或继续。
  - 掌握度三档：**生疏 / 模糊 / 掌握**（接入学习服务时写入 SQLite）
- 支持按 **单词或释义搜索**、按掌握度筛选、按字母序或出现顺序排列。

### 3. 闪卡（`cards`）

- 正面展示英文词、音标和英文造句，默认自动朗读单词与造句，可关闭或手动重听。
- 每轮打乱排序，评分后自动前进。默认略过已掌握词；「全部重来」把已掌握词也放入新一轮，不删除历史记录。
- 点击卡片或按空格翻面；左右键翻页；数字键 `1` `2` `3` 评分。

### 今日听写和学习统计

- 「今日」用中文释义和英文发音提示，提交后并排显示你的拼写和参考拼写、标出不同的字母，并显示原句和译文。评分后会显示下次复习时间。
- 「统计」显示全站词汇掌握、待复习、累计答题、最近 12 周活动和 30 篇的词表进度。格子按北京时间统计答题次数。下方的计划显示未来七天各自有多少词到期。
- 顶栏「朗读设置」可试听、选音色和语速。默认优先高质量离线音色；若设备只装有基础音色，仍用基础音色。

### 其他

- 顶栏 `A−` / `A+` 调字号（14–23px），`夜` 切昼夜模式。
- **左侧目录可折叠**：顶栏最左边的面板按钮一键收起/展开，状态会记住。窄屏下它是抽屉，点章节或点外面自动关闭。
- 目录滚动做了处理：细窄的滚动条、右侧蓝色**滚动进度轨**、上下边缘渐隐、切换章节时平滑定位到当前章。
- 快捷键：`Esc` 关掉浮层并停止朗读。


## 四、怎么改内容

**现在 30 章全部补完了**：3,032 句逐句中文对照译文 + 5,061 条词汇例句（4,154 个去重词），全部通过 `tools/validate_content.mjs` 校验。

### 改某一句译文

1. 找到那一章的 `content/chNN.sentences.json`，`sentences` 数组的第 N 项就是第 N 句的译文（编号 = 正文句子顺序，跨段落连续编号）。
2. 改完运行 `node tools\build_site_data.mjs`，站点数据自动更新。

### 改某个词的例句

`content/chNN.vocab.json` 里 `words[单词].ex` 数组，顺序与词表里该词的**行序**一致（多词性词就按行序放多个例句，每个对应一个词性）。改完同样跑一次 build。

### 加一个新章节的内容

1. 拆句 + 拿词表清单：

```bash
node tools\dump.mjs "词汇故事集\Chapter_02_Orientation.md" dump02.txt
node tools\vocablist.mjs "词汇故事集\Chapter_02_Orientation.md" vocab02.txt
```

2. 或者直接用**任务简报**：`content/_briefs/chNN.md` 里面已经把编号句子和按行序的词表排好了，照着写两个 JSON 即可：

```json
{ "sentences": [ "第一句的中文译文", "第二句的中文译文" ] }
```

```json
{ "words": { "ability": { "ipa": "/əˈbɪləti/", "ex": [ { "en": "...", "cn": "...", "note": "可选" } ] } } }
```

- 数组长度必须和句子数**完全一致**，词条 `ex` 数量必须和该词的词表行数一致。
- 键用**小写单词**；词表里写成 `a/b` 的照抄（如 `exam/examination`）。

3. 校验 + 重建：

```bash
node tools\validate_content.mjs chNN     # 必须输出 "✓ chNN ... 全部通过"
node tools\build_site_data.mjs           # 重新生成 site/data/
```

### 文风规范（全站统一）

- **人名地名一律音译**：大卫 / 马克 / 萨拉 / 海州 / 海州大学 / 周女士 / 吴先生 / 陈女士 / 顾先生 / 韩太太 / 书架。
- **中文引号用弯引号 “ ”**，破折号用 ——（两个 U+2014）。
- 数字按中文习惯写。
- 例句是**可迁移的通用句**（不是照抄正文原句），贴住该词性那个义项。

批量纠偏脚本（改完跑一下）：

```bash
node tools\normalize_punct.mjs --write   # 直角引号 → 弯引号，破折号补成对
node tools\normalize_names.mjs --write   # 残留的英文人名 → 音译
```

## 五、几个实现上的注意点

- **目标词高亮**用的是 `plan/check.py` 里同一套词形变体规则（`-s/-es/-ed/-ing`、y→ies、去 e 双写等），所以站上标出来的词和原项目校验过的词完全一致：每章 137–139 个目标词，**全部在正文里出现，零遗漏**。
- **切句器会合并称谓缩写**：`Ms. Chen said` 不会被拆成两句。30 章共修掉 49 处（9 章受影响），每处合并后的句子都重译过。
- **多词性词的原文例句**：一个词在正文里只出现 N 次，就只能给 N 个词性行配到不同的原文句。配不上的那个词性，卡片上会明说「本篇正文只出现了该词的其他词性用法」，不会硬凑。
- **数据用 classic `<script>` 而不是 fetch**，就是为了让 `file://` 双击打开也能跑（fetch 会被浏览器拦）。
- **离线网页的状态存在 localStorage**（key `cet4.reader.v2`），换浏览器或清缓存会丢。

## 六、截图 / 回归

```bash
node tools\serve.mjs 8848                      # 先起服务
powershell -File tools\shot.ps1 -Url "http://127.0.0.1:8848/_dev/shot.html?view=read&pop=basin" -Out "pop.png" -W 1440 -H 900
```

`_dev/shot.html` 支持这些参数：`view`(read/vocab/cards)、`ch`(ch01…ch30)、`theme`(paper/night)、`pop`(点开某个词)、`expand=1`(展开全部译文)、`w`/`h`(iframe 宽高，用来测窄屏)、`diag=1`(输出溢出元素)。

已验证：桌面 1440 / 1024 / 816、移动 375 均无横向溢出；Lighthouse 无障碍 / 最佳实践 / SEO 三项满分；昼夜两套主题的正文对比度均达 WCAG AA。

## 七、已知限制

- **朗读用的是浏览器自带的 TTS**（Web Speech API），不联网，但**要系统装了英文语音包**才出声。Windows 10/11 自带 Microsoft David / Zira，一般开箱可用；如果点了没声音，去「设置 → 时间和语言 → 语音」里装一个英语语音。逐词高亮依赖 Chrome/Edge 的 `boundary` 事件，Firefox 里会整段朗读但不高亮。
- 闪卡的「上一张 / 下一张」在窄屏上按钮会挤，注意留白。
- 掌握度存在 `localStorage`，换浏览器或清缓存会丢。

## 今日学习与全站词典

使用 [C++ 学习服务](../backend/README.md)打开站点，数据库会保存阅读位置、到期时间和答题历史。「今日」可继续上次阅读或练习到期词；正文每段下方可直接练习原句；「查词」支持英文和中文释义搜索并定位原句。
